# Scripts

## `build-release.ps1`

Builds the Tauri Windows desktop app and copies the double-clickable executable to:

```text
release/Sleepers Researcher.exe
```

It also copies any NSIS installer generated by Tauri from `src-tauri/target/release/bundle/nsis/` into `release/`.

Run from the project root with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1
```

Or double-click `build-release.cmd` from File Explorer.
